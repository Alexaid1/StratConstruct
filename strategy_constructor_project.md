# Конструктор торговых стратегий — Проектный документ

## Описание продукта

Веб-приложение, которое позволяет трейдерам без навыков программирования создавать, настраивать и тестировать торговые стратегии на исторических данных криптовалютного рынка. Пользователь собирает стратегию из готовых блоков — выбирает индикаторы, задаёт параметры, определяет условия входа и выхода из позиции — и получает аналитику эффективности с AI-комментарием.

---

## Для кого

**Основная аудитория:** Крипто-трейдеры с опытом 6–18 месяцев, торгующие руками. Знают что такое RSI и EMA, слышали про стратегии, но не умеют и не хотят писать код. Хотят проверить свои идеи до того, как потеряют деньги на реальном рынке.

**Боль:** "Я хочу проверить, работает ли моя идея — но не умею кодить, а платить разработчику за каждую гипотезу нереально."

**Не для кого:** Профессиональные квантовые аналитики, алго-трейдеры с опытом кодинга — для них есть QuantConnect и Python.

---

## Конечный вид продукта (MVP)

Веб-приложение (десктоп-первичный, мобильная адаптация вторична).

### Пользовательский путь

1. Пользователь открывает конструктор
2. Выбирает актив (BTC/USDT, ETH/USDT и др.) и таймфрейм
3. Добавляет индикаторы из библиотеки, настраивает параметры
4. Задаёт условие входа в позицию (например: RSI < 30 И цена выше EMA 200)
5. Задаёт условие выхода (тейк-профит, стоп-лосс, или сигнал индикатора)
6. Запускает бэктест на выбранном диапазоне дат
7. Получает отчёт: ключевые метрики + график + AI-комментарий с рекомендациями

## Отчёт по бэктесту

### Метрики
- Общая доходность (%)
- Количество сделок
- Процент прибыльных сделок
- Максимальная просадка (%)
- Sharpe Ratio
- Средняя прибыль / средний убыток на сделку

### Визуализация
- График цены с нанесёнными точками входа/выхода
- График кривой доходности стратегии

### AI-комментарий (Claude API)
- Краткая оценка стратегии
- Выявленные слабые места
- 2–3 конкретных рекомендации по улучшению


## Важные технические ограничения (не игнорировать)

**Lookahead bias** — индикатор не должен использовать данные свечи, которая ещё не закрылась. Это самая частая ошибка в бэктестах.

**Комиссии** — всегда учитывать комиссию биржи (минимум 0.1% на сделку). Без этого результаты нереалистичны.

**Overfitting** — в AI-комментарии предупреждать пользователя если стратегия показывает слишком хорошие результаты на истории.
