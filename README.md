# StratConstruct

Два инструмента для частного инвестора в одном приложении на Streamlit:

- **Конструктор стратегий** - собери торговую стратегию из блоков без кода и проверь её на истории.
- **Тренажёр трейдера** - игра на реальных графиках Мосбиржи: угадай, что будет дальше, и узнай, есть ли у тебя навык или просто везёт.

Живая версия конструктора: https://stratconstruct-4p9uexcraivwmrzzv7xtus.streamlit.app/

> Это учебный проект, а не инвестиционная рекомендация. Прошлые результаты не гарантируют будущих.

## Конструктор стратегий

1. Выбираешь актив (25 крипто-пар), биржу и таймфрейм.
2. Добавляешь индикаторы: RSI, MACD, EMA, SMA, Bollinger Bands, Stochastic, ATR, Volume SMA, CCI, Supertrend.
3. Задаёшь условия входа и выхода (сравнения, пересечения, AND/OR), тейк-профит и стоп-лосс.
4. Запускаешь бэктест и получаешь доходность, просадку, Sharpe, долю прибыльных сделок и график со входами и выходами.
5. Claude разбирает результат: слабые места, риск переобучения, что улучшить.

Бэктест упрощённый: только покупки, одна позиция за раз, исполнение по открытию следующей свечи, комиссия учитывается, проскальзывание нет. Защита от look-ahead bias проверена тестами.

## Тренажёр трейдера

Тебе показывают кусок реального графика акции Мосбиржи. Тикер и даты скрыты до ответа, поэтому память не подсказывает - остаётся только чтение графика.

- **Быстрый режим:** вверх, вниз или боковик, плюс уверенность. Очки считаются по Brier-оценке: выгодно ставить ту уверенность, которую чувствуешь.
- **Режим «Сделка»:** лонг или шорт со стопом и тейком, результат в R (кратных риску).
- **Разбор раунда:** что показывали индикаторы и что случилось дальше. Разбор написан на правилах, без AI.
- **Журнал и статистика:** точность против «наугад» и против «всегда самый частый исход», доверительные интервалы, калибровка уверенности и оценка того, сколько раундов нужно, чтобы отличить навык от везения.

Данные: 14 акций, дневки с 2015 года и часовики за 3 года, заседания ЦБ и дивиденды.
Раунды собираются без подглядывания в будущее: индикаторы считаются только по тому, что видит игрок. Часть слишком случайных раундов отсеивается, но не все - на настоящем рынке индикаторы ошибаются, и тренажёр не должен учить обратному.

Тренажёр лежит в ветке `feature/trainer` и ещё не влит в `main`.

## Запуск

Нужен Python 3.12 или новее (проверено на 3.13).

```bash
pip install -r requirements.txt
streamlit run app.py
```

Тренажёр работает сразу: данные лежат в `data/`. Конструктору для AI-разбора и аналитики нужны ключи, они необязательны. Положи их в `.env` или в секреты Streamlit:

| Переменная | Для чего |
|---|---|
| `CLAUDE_API_KEY` | AI-разбор бэктеста (`CLAUDE_BASE_URL` и `CLAUDE_MODEL` - по желанию) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | отзывы и простая аналитика визитов |

Тесты:

```bash
pytest tests --deselect tests/test_fetcher.py
```

`test_fetcher.py` ходит на биржу по сети, поэтому его запускают отдельно. Остальные 189 тестов работают офлайн.

Обновить котировки тренажёра:

```bash
python scripts/fetch_moex.py
```

## Устройство

```text
app.py                 вход и меню разделов
app_pages/             страницы: constructor.py, trainer.py
backtester/ strategy/  движок бэктеста, модель стратегии, валидатор
indicators/ data/      индикаторы, загрузка свечей с бирж (ccxt)
ai/ analytics/         AI-разбор через Claude, отзывы в Telegram
trainer/               раунды, исходы и очки, режимы, журнал, статистика, разбор
trainer/chart/         игровой компонент на Lightweight Charts
data/                  котировки Мосбиржи (parquet), события и дивиденды (csv)
scripts/               загрузка и калибровка данных
tests/                 автотесты
```

Журнал тренажёра - файл SQLite, привязанный к анонимному id браузера. На бесплатном хостинге Streamlit он обнуляется при перезапуске, поэтому есть экспорт и импорт в CSV.

## Куда развиваем

Идея на ближайшее время - AI-наставник: код считает поведенческие метрики игрока (точность, калибровка, стопы в рыночном шуме), а LLM объясняет их простым языком и подбирает тренировку. Это план, в коде его пока нет.
